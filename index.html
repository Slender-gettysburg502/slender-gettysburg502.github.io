This tool helps you file your Indian ITR-2 for the assessment year 2026-27. It uses automation to handle complex tax documents. You can use it to reconcile your AIS, TIS, Form 26AS, Form 16, and broker data. The tool classifies capital gains, compares tax regimes, and creates a valid JSON file for the tax department.

📝 How to Use the Tool

The software simplifies the filing process into a few logical steps:

  • Load Documents: Select your downloaded tax documents like Form 16 and TIS files.
  • Review Data: The tool reads these files and shows you a summary of your income and tax deductions.
  • Classification: The program identifies your capital gains and sorts them by category.
  • Comparison: Choose between the old and new tax regimes. The tool calculates your tax liability for both options so you pick the best one.
  • Export: Generate your ITR-2 JSON file when you finish your review.

🛡️ Privacy and Safety

Your tax data remains on your local machine. The software processes your documents without sending sensitive personal information to external servers. You keep full control of your financial records at all times.

💡 Frequently Asked Questions

Does this tool file my taxes automatically? No, it prepares the data and creates a JSON file. You must upload this file to the official Income Tax India portal to complete your filing.

Is this software free? Yes, the tool is open source and available for everyone to use.

What if the tool fails to read a document? Check if your document is in the correct PDF format provided by the tax portal. If issues persist, verify that you are using the latest version of the software.
